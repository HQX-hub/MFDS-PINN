# MFDS-PINN

Project page for:

**Causal Physics-Informed Reconstruction of Unsteady Flow Around Obstacles**

## Overview

MFDS-PINN is a physics-informed framework for sparse spatiotemporal
reconstruction of two-dimensional unsteady flows around obstacles.

The framework combines mixed-feature embeddings, masked local temporal
attention, and a mixed-variable stream-function–pressure–stress
formulation. It is also extended to reconstruct coupled flow and
temperature fields in mixed-convection cases.
